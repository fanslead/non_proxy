# NonProxy 0.0.1 Developer Preview

NonProxy `0.0.1` 是首个可下载的开发预览版，提供 macOS Universal DMG，以及 Windows
x64、ARM64 两套开发签名包。本版本面向源码审阅、界面体验和隔离测试环境验证，不是已完成
平台生产签名的正式版本。

## 本版本包含

- 面向应用、网站和应用与目标组合的直连策略管理。
- macOS Transparent Proxy、DNS Proxy、浏览器学习与本地控制面实现。
- Windows WFP Redirect、DNS/UDP 数据面、桌面端和安装 Bootstrap 实现。
- Surge、Mihomo 与 sing-box 的集成适配，以及独立代理出站能力。
- 可审计的连接决策、出口验证、诊断导出和失败恢复链路。

## 下载

- `NonProxy-0.0.1-macos-universal-development.dmg`
- `NonProxy-0.0.1-windows-x64-development.zip`
- `NonProxy-0.0.1-windows-arm64-development.zip`
- `SHA256SUMS`

下载后请先使用 `SHA256SUMS` 校验文件完整性。

## 开发签名限制

- macOS 包使用 Apple Development 身份签名，未使用 Developer ID、未公证，也没有 NonProxy
  专用 Provisioning Profile。因此可以验证 App、Bundle 与交互，但不能把系统扩展激活结果视为
  正式验收。
- Windows 包使用临时自签名开发证书，WFP Driver 未经 Microsoft Hardware Dev Center 签名。
  仅应在隔离测试机或虚拟机中显式信任证书并启用 Test Signing；不要降低日常主力机的启动安全
  设置。

完整构建、信任与卸载说明见
[开发预览版构建与签名](../DEVELOPMENT_RELEASE.md)。
