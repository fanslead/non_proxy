# ADR-0017：显式管理桌面生命周期与真实可用的本地设置

## 状态

已接受。

## 背景

NonProxy 的 `gatewayd` 和平台数据面不依赖主窗口存活。桌面端如果仍使用“最后窗口关闭
即退出”的默认生命周期，用户关闭窗口后既无法判断规则是否仍在运行，也无法从菜单栏
恢复界面。原设置页还展示了开机启动、数据面生命周期和历史记录开关，但这些控件没有
对应的平台或控制面实现；智能学习页也把完整存在于浏览器扩展中的标签页会话错误地表现
为桌面端可启动的全局会话。

## 决策

1. 桌面 UI 使用 Avalonia `OnExplicitShutdown`。普通关闭主窗口只隐藏界面；托盘、macOS
   应用菜单、Dock 菜单和 macOS `Reopen` 激活都可以恢复同一个窗口。
2. 菜单使用“退出 NonProxy 界面”这一明确文案。它只结束 UI 进程，不停止
   `gatewayd`、Provider 或已激活规则。系统退出请求不被关闭到托盘逻辑拦截。
3. 退出请求只有在生命周期确认接受后才进入退出状态；被其他关闭处理器拒绝时恢复正常
   的关闭到托盘行为，避免界面和托盘同时消失。
4. 当前唯一可变的桌面设置是主题。主题写入当前用户本地应用数据目录，采用同目录临时
   文件加原子替换；未知、损坏或超过 64 KiB 的内容回退为系统主题。
5. 设置页不展示尚未接通的开机启动或历史开关。窗口/后台和诊断隐私边界以只读说明
   呈现，避免“保存成功但行为没变”。
6. 智能学习页只解释真实入口：浏览器扩展基于当前标签页创建有时限会话、聚合候选并由
   用户确认。应用直连继续依赖平台验证的应用身份，不要求用户学习或填写服务器地址。

## 后果

- macOS 和 Windows 共享同一套窗口/托盘命令和主题设置实现。
- 设置文件不包含代理凭据、访问历史或网络目标，不进入控制面权威数据库。
- 浏览器标签页 capability 不会被桌面进程伪造或跨页面共享。
- Headless 测试只能证明菜单结构、图标解码、设置持久化和 AXAML 行为；真实 macOS
  菜单栏、Dock 恢复和 Windows 通知区域仍需在正式包中验收。
