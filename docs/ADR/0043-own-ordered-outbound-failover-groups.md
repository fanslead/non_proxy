# ADR-0043：使用有序出口组承载自动故障切换

- 状态：已接受
- 日期：2026-08-02

## 背景

策略若直接引用某个瞬时节点，节点失效后只能改写并重新发布策略，既慢又会把运行态健康
状态污染到用户配置。把“失败就尝试下一个节点”直接写进每条 TCP/UDP 连接也不安全：用户
目标本身可能不可达，不能据此把一个代理节点判为故障，更不能在日志中记录用户目标来解释
切换。远程订阅还会增删节点，因此出口组必须有独立、可并发更新的权威身份和成员顺序。

## 决策

1. `OutboundGroupId` 与 `OutboundId` 使用不同领域类型。控制契约和策略快照必须显式区分
   “单出口”与“出口组”，不得靠同名字符串、前缀或查询数据库猜测目标类型。
2. 首版只提供 `failover` 策略：成员顺序就是优先级，必须包含 2～32 个不重复、可由内置
   数据面连接的出口；不允许嵌套出口组。HTTP CONNECT 可以成为 TCP-only 组成员，组能力
   是所有成员能力的交集，编译时仍要满足规则所需传输和地址族。
3. `outbound_group` 与 `outbound_group_member` 是 SQLite 权威状态。创建从 revision 1
   开始，更新必须提交当前 revision 并递增 1；名称、策略、完整成员顺序和审计事件在同一个
   `BEGIN IMMEDIATE` 事务中写入。成员外键使用 `ON DELETE RESTRICT`，避免订阅刷新或
   删除悄悄移除仍被组引用的节点。
4. 策略决定稳定的组，不决定当前节点。发布快照时固化组 ID、revision、有序成员和交集
   能力；Provider 只携带组目标进入 gatewayd，gatewayd 再按当前健康观察解析具体出口。
   配置 revision 变化会使旧选择和旧健康观察失效。
5. 自动健康探测只连接服务端固定的公共目标，不携带用户正在访问的域名。调度启动时立即
   探测，之后使用有界并发和抖动间隔；连续两次失败才降级，连续两次成功才恢复，避免短暂
   抖动来回切换。观察超过 60 秒视为未知。
6. 新 flow 选择顺序中的第一个新鲜 `READY` 成员；没有已验证成员时组不可用，并由策略的
   `FailureMode` 决定失败关闭或显式直连回退。未知或失败成员不能因为一次用户目标连接成功
   或失败改变健康状态。
7. 当前成员变化只影响新建 TCP 和新建 UDP session；已建立 TCP 不迁移。每次组选中成员
   发生变化时写一条不含用户目标的审计事件，记录组、旧成员、新成员、组 revision 和稳定
   原因码，不能为每条用户连接制造切换日志。
8. 删除出口组必须通过 revision CAS，并在仍被策略或默认路由引用时拒绝。已发布快照固化组
   目录，继续按该不可变版本运行；删除组不删除成员出口，删除订阅源或节点仍受成员外键和
   现有引用检查保护。首版运行态代理覆盖只接受单出口，不伪装成组引用。
9. 出口组可以成为默认代理目标，但必须至少包含两个全部支持完整网关的启用成员，且至少一个
   成员已经连续两次取得新鲜 `READY`。默认路由、显式组 decision 与 pending 快照在同一事务
   发布；编辑当前默认组时，组 revision 与下一版 pending 快照也必须同事务提交，已有 pending
   则两者一起回滚。控制契约必须在系统状态、出口目录和组目录中一致返回默认组身份。

## 后果

- 用户规则和订阅刷新不再因单个节点切换而重写；macOS 与 Windows 可以共享同一组配置、
  健康状态机和审计语义。
- 冷启动期间在首轮固定目标探测完成前，fail-closed 组会短暂不可用。这比在没有证据时把
  未验证节点投入用户流量更可控，桌面端必须明确显示“正在验证”。
- 共享桌面端用独立子 View/ViewModel 管理组，成员顺序以线路栈呈现；读取时必须核对出口目录
  与组目录的 routing revision 和默认组身份，避免把两个时点的目录拼成一个界面状态。
- 首版不提供随机、轮询、按延迟负载均衡、嵌套组或已建立连接迁移；若以后新增策略，必须
  新增契约枚举、选择确定性和隐私边界，不能改变 `failover` 的既有语义。

## 验收边界

仓储测试必须证明成员顺序、revision CAS、原子回滚、成员类型约束和删除不连带删除出口。
运行时完成后还必须证明固定目标探测、连续成功/失败门槛、新 flow 切换、旧连接不迁移、
失败模式、快照固化、审计去敏以及订阅成员引用保护。仅有数据库表或手动握手测试不能宣称
自动故障切换可用。
