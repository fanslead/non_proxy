# ADR-0010：由 gatewayd 生成可预览的脱敏诊断包

- 状态：已接受
- 日期：2026-07-31

## 背景

诊断数据横跨策略权威库、运行状态、组件事件和连接路径证据。若桌面 UI 直接读取
SQLite、能力文件或平台日志，会破坏“只有 `gatewayd` 访问权威数据”的边界，也会
增加误打包凭据、代理端点和用户访问目标的风险。另一方面，只有一个不可解释的压缩
文件不利于用户在发送前检查内容。

控制契约已经预留 `ExportDiagnostics`，但此前固定返回功能不可用；桌面端按钮也被
禁用。因此产品缺少“本地生成、自动脱敏、用户预览、由用户决定是否分享”的闭环。

## 决策

1. `gatewayd` 是诊断文档的唯一生成者。桌面端只能通过带会话能力的
   `ExportDiagnostics` 请求导出，不读取 SQLite、Keychain、Credential Manager 或
   Provider 私有文件。
2. 首版格式为带 `schema_version` 的 UTF-8 JSON。JSON 便于用户直接预览，后续如需
   外层压缩包，仍必须保留同一可读清单和脱敏语义。
3. 桌面端固定请求 `STRICT`：不包含逐连接样本，只保留聚合计数、组件状态和稳定
   错误码。契约保留 `STANDARD` 给明确的支持场景；其中应用、目标、接口和出口只使用
   每次导出独立随机盐值的短标识，盐值不写入文档。
4. 两种级别都禁止写入凭据、凭据引用、代理端点、订阅地址、Cookie、网络载荷、完整
   URL、原始应用标识和原始访问目标。配置只输出按来源、动作和出口类型聚合的计数。
5. 默认时间范围为最近 24 小时，自定义范围也不得超过 24 小时或指向未来。每次最多
   检查最近 500 条决策；标准模式最多输出 50 条脱敏样本；最近错误最多输出 100 条；
   整个 JSON 硬上限为 1 MiB，并明确标记检查是否截断。
6. 文件写入状态目录下的 `diagnostics/`。Unix 目录为 `0700`、文件为 `0600`；Windows
   继承安装器为状态目录设置的受限 ACL。目录、临时文件或目标文件类型异常时拒绝，
   使用随机文件名、`create_new`、同步和同目录原子发布。
7. 响应返回诊断 ID、绝对本地路径、大小、SHA-256、实际脱敏级别、有效时间范围、
   内容分区和记录数量。桌面端在页面内展示这些预览信息，并明确文件不会自动上传。
8. 响应新增字段只使用新的 protobuf field number；旧字段保持不变，旧客户端仍可忽略
   预览元数据。

## 结果

- 用户可以在发送前检查内容范围、时间、大小、哈希和本地 JSON。
- 高权限状态不会被复制到 UI 进程重新拼装，隐私规则在单一可信边界中执行。
- 严格模式不会因为“诊断”而重新暴露本来已经脱敏的连接目标。
- 当前包只包含 `gatewayd` 可验证的组件事件和路径观测；它不把构建或导出成功表述为
  System Extension、WFP、真实 VPN 共存或公网出口已经验收。
- 诊断文件由用户自行管理和分享；产品不自动上传，也不在本批次引入遥测。
